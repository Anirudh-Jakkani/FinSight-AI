Privacy Policy

FinSight AI is a self-hosted, single-instance educational project — there is no company collecting your data.

Where your data lives

All transaction, account, and analytics data is stored in a PostgreSQL database that you run yourself, locally. Nothing is uploaded to a hosted FinSight service — there isn't one. The static dashboard talks only to the FastAPI backend running on your own machine.

No accounts, no authentication

This project does not implement login or authentication. A "User ID" is a plain numeric identifier used to scope queries, not a real account — do not deploy this as-is anywhere that isn't fully trusted, since any caller who can reach the API can pass any user ID.

Third-party AI processing

The "Ask FinSight" summary and chat features are the one place this application sends your data outside your own machine: your verified financial figures (income, expenses, category breakdowns, recurring payments, anomalies, forecasts, and — for chat — recent transactions) are sent to a third-party large language model via OpenRouter, so it can narrate them in plain language. That provider's own privacy policy governs how they handle that request. If you don't want this, simply don't use the AI summary or chat features — every other part of the dashboard works without them.

No tracking or analytics

The frontend loads no analytics, advertising, or tracking scripts. The only external network request it makes, besides your own backend, is loading the Chart.js library from a public CDN and (when you use it) the AI features described above.

Browser storage

Your theme preference (light/dark) is saved in your browser's localStorage so it persists between visits. Nothing else is stored client-side.

FinSight AI — educational personal-finance analytics. Not financial advice.
