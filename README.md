# FinSight AI
*Understand where your money goes.*

Educational personal-finance analytics: import a bank statement, categorize transactions,
view spending analytics, recurring payments, unusual spending and forecasts, and ask an AI
analyst questions grounded in verified calculations. **Not financial advice.**

**Status:** Through Phase 8.8 (production deployment config). See `docs/`.

## Run locally
```bash
docker compose up -d db            # PostgreSQL
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env               # fill in LLM values later
alembic upgrade head               # create/update database schema
uvicorn app.main:app --reload
```
Open http://127.0.0.1:8000/docs and try `/health` and `/health/db`.

## Demo data
`data/sample_transactions.csv` is **synthetic**, generated by `data/generate_sample_data.py`.

## Deploying
```bash
docker compose up -d --build       # PostgreSQL + API
```
See `docs/deployment.md` for required production environment variables and the
rest of the deployment guide.
